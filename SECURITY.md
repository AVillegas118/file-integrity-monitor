# Politica de seguridad

Este es un proyecto educativo y defensivo. No debe considerarse un reemplazo de
controles profesionales como permisos correctos, copias de seguridad, EDR o un
SIEM.

Si encuentras un problema de seguridad, evita publicar datos sensibles o una
prueba destructiva. Abre un aviso privado desde la seccion **Security** del
repositorio de GitHub y explica:

- que comportamiento observaste;
- como se puede reproducir con datos ficticios;
- que version utilizaste;
- que impacto defensivo podria tener.

No incluyas contrasenas, tokens, llaves privadas ni archivos personales.
